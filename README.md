# PoliCert

Sistema per l'emissione, la condivisione e la verifica di certificati accademici su blockchain.
Progetto per il corso di Ingegneria del Software, Politecnico di Bari.

## Avvio rapido

```bash
npm install
npx hardhat compile
npx hardhat test
```

## Struttura

- `contracts/` smart contract Solidity
- `test/` test degli smart contract
- `backend/` API e logica off-chain
- `frontend/` interfaccia web
- `docs/` requisiti, UML, relazione, verbali

Le regole di lavoro sono in [CONTRIBUTING.md](CONTRIBUTING.md).
